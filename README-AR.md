# دليل معلمة غرس القيم — حزمة Netlify الخفيفة

هذه الحزمة تضم النسخة الكاملة من دليل «وحدة الليل والنهار»، مع جميع الصور
والبطاقات والخطوط والتسجيلات والملفات التعليمية المستخدمة داخل الموقع. جرى
تحسين أحجام الصور والمقاطع لتسريع الرفع وفتح الصفحات، من دون حذف محتوى الدليل.

## الرفع المباشر إلى Netlify

1. حمّلي ملف `ghars-teacher-guide-netlify-lite.zip`.
2. افتحي حسابك في Netlify، ثم انتقلي إلى:
   `https://app.netlify.com/drop`
3. اسحبي **ملف ZIP نفسه** إلى مساحة الرفع؛ لا تفكّي ضغطه ولا ترفعي الملفات
   واحدًا واحدًا.
4. انتظري اكتمال النشر؛ سيعطيك Netlify رابطًا منتهيًا بـ `netlify.app`.
5. من إعدادات الموقع يمكنك تغيير اسم الموقع أو ربط نطاق خاص لاحقًا.

ملف الرفع المباشر جاهز للنشر كما هو، ولا يحتاج إلى أمر بناء أو تثبيت برامج.

## ربطه بمستودع للتطوير المستمر

1. فكّي ضغط الملف نفسه.
2. ارفعي محتوياته إلى مستودع GitHub أو GitLab خاص بالمشروع.
3. في Netlify اختاري **Add new project** ثم **Import an existing project**.
4. اربطي المستودع؛ إعدادات `netlify.toml` الموجودة في الحزمة تحدد مجلد النشر
   تلقائيًا.
5. عند إضافة وحدة أو تعديل درس مستقبلًا، يُنشَر التحديث بعد رفع النسخة الجديدة
   إلى المستودع.

## بنية الملفات

- `guide.html`: صفحة الدليل الرئيسية ومحتوى الوحدة الحالية.
- `assets/`: الصور والفيديوهات والتسجيلات والبطاقات والملفات القابلة للتنزيل.
- `brand/`: شعارات غرس القيم وأيقونات المواد والأركان.
- ملفات `CSS` و`JS`: التصميم والتبويبات والتفاعل وبطاقات تخطيط الدروس.
- `netlify.toml`: إعدادات النشر التلقائي عند ربط الحزمة بمستودع.
- `_redirects` و`_headers`: إعدادات التوجيه والتخزين المؤقت والأمان في Netlify.
- `index.html`: مدخل الموقع.

## إضافة الوحدات القادمة

النسخة الحالية هي الأساس المعتمد للموقع. عند بناء بقية الوحدات سنضيفها إلى
المشروع نفسه، وننشئ مدخلًا موحدًا للتنقل بينها مع بقاء الهوية والأشرطة
والتبويبات وأدوات المعلمة مشتركة.

لا تحذفي مجلدَي `assets` أو `brand`، ولا تغيّري أسماء الملفات داخلهما؛ لأن
صفحات الدليل ترتبط بها مباشرة.
