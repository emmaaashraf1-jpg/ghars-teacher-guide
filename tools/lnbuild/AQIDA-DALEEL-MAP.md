# خريطة أدلّة القواعد العقدية في قسم «الضابط» (لكلّ قاعدة دليلٌ شرعيّ + مرجع عند الحاجة)

القاعدة: كلُّ قاعدةٍ/مفهومٍ عقديٍّ في قسم «الضابط العقديّ» يُذيَّل بدليلٍ من الكتاب أو السنّة الصحيحة داخل `<span class="src">الدليل: …</span>`. أمّا بنودُ «حدُّ ما يُقال» و«الرفق بالمتعلّم» و«ضبط النطق» و«الكلمة الطيّبة» فهي توجيهٌ تربويّ لا تحتاج عزوًا.

| القاعدة العقدية | الدليل الشرعيّ المعتمد |
|---|---|
| إثبات الأسماء والصفات بلا تكييف/تمثيل/تعطيل/تحريف | ﴿لَيْسَ كَمِثْلِهِ شَيْءٌ وَهُوَ السَّمِيعُ الْبَصِيرُ﴾ [الشورى ١١] |
| إثبات اسمٍ/صفةٍ معيّنة | آيةُ ورودِه (المذكورة في الدرس) + ﴿لَيْسَ كَمِثْلِهِ شَيْءٌ﴾ [الشورى ١١] عند الحاجة |
| الربوبيّة لله وحده / الخلق لله وحده | ﴿هَلْ مِنْ خَالِقٍ غَيْرُ اللَّهِ﴾ [فاطر ٣] |
| الربوبيّة توجب العبادة (من الربوبية إلى العبادة) | ﴿ذَٰلِكُمُ اللَّهُ رَبُّكُمْ … خَالِقُ كُلِّ شَيْءٍ فَاعْبُدُوهُ﴾ [الأنعام ١٠٢] · ﴿اعْبُدُوا رَبَّكُمُ الَّذِي خَلَقَكُمْ﴾ [البقرة ٢١] |
| النعمُ من الله وحده / شكرُ المُنعِم | ﴿وَمَا بِكُم مِّن نِّعْمَةٍ فَمِنَ اللَّهِ﴾ [النحل ٥٣] · ﴿لَئِن شَكَرْتُمْ لَأَزِيدَنَّكُمْ﴾ [إبراهيم ٧] |
| الشكرُ عبادة / شكرُ نعمة العقل والحواسّ | ﴿وَجَعَلَ لَكُمُ السَّمْعَ وَالْأَبْصَارَ وَالْأَفْئِدَةَ لَعَلَّكُمْ تَشْكُرُونَ﴾ [النحل ٧٨] |
| توحيد السؤال والاستعانة / لا يُدعى ولا يُتوكّل إلّا على الله / لا يُستغاث إلّا بالله | ﴿إِيَّاكَ نَعْبُدُ وَإِيَّاكَ نَسْتَعِينُ﴾ [الفاتحة ٥] + حديث «وإذا سألت فاسأل الله» [الترمذي، حسن صحيح] |
| لا يُقصَد بالحاجات إلّا الله (الصمد) | ﴿اللَّهُ الصَّمَدُ﴾ [الإخلاص ٢] + ﴿إِيَّاكَ نَعْبُدُ وَإِيَّاكَ نَسْتَعِينُ﴾ [الفاتحة ٥] |
| التسخيرُ من الله | ﴿وَسَخَّرَ لَكُم مَّا فِي السَّمَاوَاتِ وَمَا فِي الْأَرْضِ جَمِيعًا مِّنْهُ﴾ [الجاثية ١٣] |
| الهدايةُ من الله وحده | ﴿إِنَّكَ لَا تَهْدِي مَنْ أَحْبَبْتَ وَلَٰكِنَّ اللَّهَ يَهْدِي مَن يَشَاءُ﴾ [القصص ٥٦] |
| التفكّرُ عبادة | ﴿إِنَّ فِي خَلْقِ السَّمَاوَاتِ وَالْأَرْضِ … لَآيَاتٍ لِّأُولِي الْأَلْبَابِ * الَّذِينَ … يَتَفَكَّرُونَ فِي خَلْقِ السَّمَاوَاتِ وَالْأَرْضِ﴾ [آل عمران ١٩٠–١٩١] |
| بديعُ خلق الله / إتقانُ الخلق / النظام آية | ﴿صُنْعَ اللَّهِ الَّذِي أَتْقَنَ كُلَّ شَيْءٍ﴾ [النمل ٨٨] · ﴿الَّذِي خَلَقَ سَبْعَ سَمَاوَاتٍ طِبَاقًا … فَارْجِعِ الْبَصَرَ﴾ [الملك ٣] |
| النظامُ من الله (العدد/الترتيب) | ﴿وَكُلُّ شَيْءٍ عِندَهُ بِمِقْدَارٍ﴾ [الرعد ٨] · ﴿إِنَّا كُلَّ شَيْءٍ خَلَقْنَاهُ بِقَدَرٍ﴾ [القمر ٤٩] |
| النهي عن تصوير ذوات الأرواح | حديث «إنَّ أشدَّ الناسِ عذابًا يومَ القيامةِ المصوِّرون» [متّفق عليه] |
| الغيبُ يُؤمَن به ولا يُجسَّد | ﴿الَّذِينَ يُؤْمِنُونَ بِالْغَيْبِ﴾ [البقرة ٣] |
| الإيمانُ بالبعث | ﴿ثُمَّ إِنَّكُم بَعْدَ ذَٰلِكَ لَمَيِّتُونَ * ثُمَّ إِنَّكُمْ يَوْمَ الْقِيَامَةِ تُبْعَثُونَ﴾ [المؤمنون ١٥–١٦] |
| توازنُ الخوف والرجاء | ﴿نَبِّئْ عِبَادِي أَنِّي أَنَا الْغَفُورُ الرَّحِيمُ * وَأَنَّ عَذَابِي هُوَ الْعَذَابُ الْأَلِيمُ﴾ [الحجر ٤٩–٥٠] |
| مراقبةُ الله / معيّتُه للطائع | ﴿إِنَّ اللَّهَ كَانَ عَلَيْكُمْ رَقِيبًا﴾ [النساء ١] · ﴿وَهُوَ مَعَكُمْ أَيْنَ مَا كُنتُمْ﴾ [الحديد ٤] |
| تعظيمُ كلام الله / الإنصات للقرآن | ﴿وَإِذَا قُرِئَ الْقُرْآنُ فَاسْتَمِعُوا لَهُ وَأَنصِتُوا لَعَلَّكُمْ تُرْحَمُونَ﴾ [الأعراف ٢٠٤] |
| الأذكارُ توقيفيّة / الاتّباعُ لا الابتداع | حديث «مَن عمِل عملًا ليس عليه أمرُنا فهو رَدّ» [مسلم] |
| الأحاديثُ حرفيّة (لا تُغيَّر) | حديث «فمَن كذبَ عليَّ متعمِّدًا فليتبوَّأ مقعدَه من النار» [متّفق عليه] |
| تعظيمُ النبي ﷺ واتّباعُه بلا غلوّ / الاقتداء بلا تصوير | ﴿قُلْ إِن كُنتُمْ تُحِبُّونَ اللَّهَ فَاتَّبِعُونِي﴾ [آل عمران ٣١] + حديث «لا تُطروني كما أطرَتِ النصارى» [البخاري] |
| توقيرُ الصحابة | ﴿وَالسَّابِقُونَ الْأَوَّلُونَ … رَضِيَ اللَّهُ عَنْهُمْ وَرَضُوا عَنْهُ﴾ [التوبة ١٠٠] |
| الاستئذانُ أدبٌ شرعيّ | ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا لَا تَدْخُلُوا بُيُوتًا غَيْرَ بُيُوتِكُمْ حَتَّىٰ تَسْتَأْنِسُوا﴾ [النور ٢٧] |
| الستر ولباس التقوى | ﴿يَا بَنِي آدَمَ قَدْ أَنزَلْنَا عَلَيْكُمْ لِبَاسًا يُوَارِي سَوْآتِكُمْ … وَلِبَاسُ التَّقْوَى ذَٰلِكَ خَيْرٌ﴾ [الأعراف ٢٦] |
| التيامنُ سنّة | حديث عائشة «كان يُعجبُه التيمّنُ في شأنه كلّه» [متّفق عليه] |
| الأخذُ بالأسباب مع التوكّل | ﴿فَإِذَا عَزَمْتَ فَتَوَكَّلْ عَلَى اللَّهِ﴾ [آل عمران ١٥٩] + حديث «اعقِلها وتوكَّل» [الترمذي] |

**مبدأ:** الدليلُ يُذكَر مختصرًا بنصّه وعزوه فقط؛ لا شرحَ من إنشائي. حيث وردت آيةُ الدرس نفسها دليلًا للقاعدة، تُستعمَل هي. المرجعُ العقديّ (كتاب التوحيد/الأصول الثلاثة/الواسطية/شرح السعدي وابن عثيمين عبر الشاملة) يُضاف فقط إذا احتاجت القاعدةُ تقريرًا زائدًا على الدليل.
