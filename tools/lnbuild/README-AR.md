# خطُّ إنتاج الدروس (tools/lnbuild)

المستودعُ الآن على **خطِّ إنتاجٍ واحد**: كلُّ درسٍ ملفُّ HTML حيٌّ، تُحدَّث لوحاتُه من فراغماتٍ مستقلّة.

## الفراغمات (مصدرُ الحقيقة للّوحات)
- `ptahdir/<lesson>.ptahdir.html` — لوحةُ «التحضير» (القسم ٠). **٩٨ فراغمة**، واحدةٌ لكلّ لقاء.
- `ilaj/<lesson>.ilaj.html` — لوحةُ «العلاج والإثراء» (الطبقة الثانية). **٩٨ فراغمة**.

## الأدوات
- `replace-ptahdir.pl <lesson.html> <ptahdir-fragment> <out>` — يستبدل لوحةَ التحضير في الدرس.
- `extract-ptahdir.pl <lesson.html> <out-fragment>` — يستخرج لوحةَ التحضير من درسٍ حيٍّ إلى فراغمة (استُعمل لتوحيد دروس علّمني).
- `add-ilaj.pl` / فراغمات `ilaj/` — تحقن لوحةَ العلاج.

## خطُّ `.dat` — **متوقّفٌ ومؤرشَف**
كانت الدروسُ الخمسةُ `ln-allamni-lesson1…5` تُبنى من `data/*.dat` عبر `build-ln.pl`، وكان ذلك المصدرُ **متأخّرًا عن الصفحات الحيّة وبلا حقلٍ للعلاج**، فأيُّ إعادةِ بناءٍ منه تُرجع الدروسَ إلى الوراء وتُسقط الطبقةَ الثانية. لذلك:
- استُخرجت لوحاتُ التحضير الخمسُ إلى `ptahdir/` (فصارت ٩٨).
- نُقلت `data/*.dat` إلى `data/_archive/` — **لا تُبنى منها الدروسُ بعد الآن**. لا تُشغّل `build-ln.pl` على هذه الدروس؛ التحديثُ يكون عبر `ptahdir/` مثل بقيّة الـ٩٣.

## الفحصُ الدائم (ثابتُ الخطّ الموحّد)
> **عددُ فراغمات التحضير = عددُ فراغمات العلاج = عددُ اللقاءات = ٩٨.**
```bash
ls tools/lnbuild/ptahdir/*.ptahdir.html | wc -l   # 98
ls tools/lnbuild/ilaj/*.ilaj.html      | wc -l     # 98
grep -l 'id="pilaj"' *.html | grep -v markaz | wc -l   # 98
```
