> **الاستخدام:** انسخي هذا القالب **لكل لقاء** (لكل مادة في كل يوم)، واملئي «✏️».
> 🔒 = ثابت (يُنسخ كما هو) · ✏️ = تكتبينه · «حسب المادة» = يختلف باختلاف المادة (انظري آخر الملف).

# الجزء الخاص بكل مادة (ما يختلف في «شرح الدرس» و«الإشارة» و«الاعتقاد» و«المفردات»)

- **كتابي المنير:** الإشارة = أبيات نونية القحطاني · المحتوى = الآيات المستهدفة + التلاوة والترديد + المعنى + التطبيق · مراجع = تفسير/تجويد.
- **علّمني ربي (الرئيسية):** الإشارة = نشيد العلم · المحتوى = الآية الكونية + التفكّر + المعنى الإيماني + السلوك.
- **أحبك ربي:** الإشارة = ﴿وَلِلَّهِ الأَسْمَاءُ الْحُسْنَى…﴾ · المحتوى = اسم الله + معناه + أثره في القلب والعمل + الدعاء به.
- **قال رسولي:** الإشارة = مقدمة لقاء الحديث · المحتوى = الحديث + الراوي + المتن + المعنى + الاقتداء + بطاقة الاعتقاد في النبي ﷺ.
- **أدب واقتداء:** الإشارة = عرض صور الأدب · المحتوى = الأدب + دليله + التمثيل العملي + الموقف.
- **لساني عربي:** الإشارة = ﴿بِلِسَانٍ عَرَبِيٍّ مُّبِينٍ﴾ · المحتوى = الحرف/الحركة/التهجئة + النطق السليم + القراءة.
- **مهاراتي:** الإشارة = ﴿إِنَّ عِدَّةَ الشُّهُورِ…﴾ (أو آية عدد مناسبة) · المحتوى = المفهوم الرياضي + المحسوس ثم الرمز.
- **مركز اللغة / مركز الرياضيات:** تطبيق عملي وتعلّم باللعب (نصف ساعة، لقاءان لكلٍّ): المهمة + الأداة/اللعبة + الناتج الملاحَظ.
