# مصادر الوحدات (units-source)

هذا المجلد يضمّ **ملفات مصدر المحتوى** لكل وحدة في منهج غرس القيم — نسخة احتياطية منظّمة ومقروءة،
تُستخدم أساسًا لبناء الدليل أو إعادة بنائه، ومنفصلة عن الأصول الإعلامية (التي تبقى في `assets/`).

## الملفات
- `_TEMPLATE-قالب-الوحدة-البنيوي.md` — **القالب الأشمل**: عناوين كل تبويب وكل درس والأجزاء الثابتة (🔒) والمتغيّرة (✏️) مع Checklist. انسخيه واملئي المتغيّر لبناء وحدة جديدة كاملة دون إغفال شيء.
- `_TEMPLATE-قالب-الدرس-الواحد.md` — **قالب تعبئة تفصيلي للدرس الواحد**: كل أجزاء اللقاء الداخلية (الإشارة/الآداب/الاعتقاد/الأهداف/سير اللقاء/النشاط المصاحب/كفارة المجلس/التقويم/الركن/المراجع). انسخيه لكل لقاء (كل مادة × كل يوم) واملئيه.
- `_TEMPLATE-unit.md` — قالب محتوى مختصر (frontmatter + أقسام).
- `_BUILD-GUIDE.md` — خطوات البناء والنشر.
- `unit-01-الليل-والنهار.md` — مصدر محتوى الوحدة الأولى (مثال محلول، مستخرَج من `guide.html`).

## الصيغة المعتمدة
كل وحدة = ملف Markdown واحد (`unit-NN-الاسم.md`) يبدأ بـ **frontmatter** (بيانات الوحدة)
ثم أقسام موحّدة: الفكرة الناظمة · منظومة الوحي · المواد السبع · خريطة الأسبوع (الأيام) ·
قائمة التجهيز · منظومة الوحدة · جرد الأصول · ملاحظات التخطيط.

## لبناء وحدة جديدة
1. انسخي `unit-01-الليل-والنهار.md` باسم الوحدة الجديدة.
2. املئي الأقسام نفسها بمحتوى الوحدة الجديدة.
3. يُبنى منها الدليل بنفس هوية `gq-redesign-v7`، ثم يُضاف إلى المنصّة (`index.html`).

## النسخ الاحتياطي
- كل commit في git = نسخة مؤرّخة.
- يُنصح بوسم عند اعتماد كل وحدة: `git tag unit-01-v1`.
- لنسخة محمولة: اضغطي مجلد الوحدة (HTML + assets الخارجية) بصيغة zip.

> ملاحظة: الأصول (صور/صوت/فيديو/PDF) لا تُضمَّن في ملفات المصدر؛ تبقى خارجية في `assets/`
> لتظل الملفات قابلة للمقارنة (diff) وخفيفة.
