# دليل بناء وحدة جديدة (بنفس طريقة وحدة الليل والنهار)

هذا الدليل يشرح خطوات تجهيز أي وحدة جديدة في منهج غرس القيم، من المحتوى إلى النشر.

## المبدأ
- **المحتوى** يُكتب أولًا في ملف `content.md` (نص منظّم، سهل التعديل والمقارنة).
- **الأصول** (صور/صوت/فيديو/PDF) تبقى **خارجية** في مجلد `assets/` — لا تُدمج داخل HTML كـ base64.
- **الهوية** (الألوان/الخطوط/التصميم) مشتركة عبر ملفات `gq-redesign-v7.css/js` — لا تُعاد كتابتها لكل وحدة.
- **الدليل النهائي** = ملف `guide-unit-NN.html` يُبنى على المحتوى بنفس هوية وحدة الليل والنهار.

## الخطوات

### 1) جهّزي المحتوى
- انسخي `_TEMPLATE-unit.md` باسم `unit-NN-الاسم.md`.
- املئي: الفكرة الناظمة، المواد السبع (ما يخص الوحدة)، خريطة الأسبوع (الأيام الستة ولقاءاتها)، التجهيز.
- قسم «منظومة الوحي» (المحاور الستة) **ثابت** — انسخيه كما هو.

### 2) جهّزي الأصول
- اجمعي صور/فيديو/صوت/أوراق عمل الوحدة في مجلد `assets/` (أسماء واضحة).
- أبقيها بأحجام محسّنة (webp للصور، mp4 خفيف للفيديو).

### 3) ابني الدليل (HTML)
- يُبنى `guide-unit-NN.html` على بنية وحدة الليل والنهار نفسها:
  - الرأس/الغلاف بهوية `gq-pro-cover` (كحلي→فيروزي→أخضر + ذهبي).
  - التبويبات: دليل الاستخدام · الفكرة الناظمة · الوحدة · خريطة الأسبوع · المتابعة · القيم والأسرة · الحصيلة اللغوية · منظومة الوحدة · أناشيد حركية · اللياقة البدنية · الأركان · دروس الأيام (5) + برنامج الوحدة.
  - «منظومة الوحي» (مصفوفة المحاور الستة) — تُنسخ كما هي من وحدة الليل والنهار.
  - يشير إلى `gq-redesign-v7.css/js` و`corner-cards-runtime.js` و`lesson-blueprints-v10.js` والأصول الخارجية.
- أضيفي أعلى الصفحة شريط المسار: `منصّة غرس القيم › أدلة الوحدات › (اسم الوحدة)`.

### 4) أضيفيها إلى المنصّة
- في `index.html`: حوّلي بطاقة «قريبًا» إلى بطاقة الوحدة الجديدة (العنوان، الوصف، الرابط `guide-unit-NN.html`، نقاط المواد السبع).

### 5) انشري
- حدّثي `CHECKSUMS.sha256` للملفات الجديدة.
- `git add` ثم `git commit` ثم `git push origin main`.
- ينشر GitHub Pages التحديث تلقائيًا خلال دقيقة–دقيقتين على نفس الرابط.
- (يُنصح) وسم الاعتماد: `git tag unit-NN-v1`.

## قائمة تحقّق سريعة قبل النشر
- [ ] `content.md` مكتمل ومراجَع.
- [ ] كل الأصول خارجية (لا base64) وموجودة في `assets/`.
- [ ] الروابط تعمل (لا 404).
- [ ] شريط المسار وروابط العودة للمنصّة موجودة.
- [ ] بطاقة الوحدة مضافة في `index.html`.
- [ ] `CHECKSUMS.sha256` محدّث (0 فشل).
