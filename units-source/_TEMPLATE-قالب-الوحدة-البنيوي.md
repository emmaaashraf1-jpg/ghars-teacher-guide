# الدروس اليومية

## بنية الدرس الموحّدة (🔒 تتكرّر في كل درس مادة — بهذا الترتيب)
1. 🔒 **بطاقة الدرس وخطة التنفيذ** (جدول زمني للقاء)
2. 🔒 **تهيئة بداية اليوم** (لأول لقاء في اليوم: سؤال اليوم، أيام الأسبوع، الطقس، نونية القحطاني)
3. 🔒 **إشارة بدء اللقاء** — ✏️ الإشارة الخاصة بالمادة (آية/نشيد/حديث) + فيديو الإشارة
4. 🔒 **آداب اللقاء**
5. 🔒 **الاعتقاد** (بطاقة الاعتقاد المناسبة للمادة)
6. 🔒 **مراجعة سريعة**
7. 🔒 **شرح الدرس** — ✏️ محتوى المادة (انظري السطر الخاص بكل مادة أدناه)
8. ✏️ **النشاط المصاحب** (نشاط تطبيقي للّقاء)
9. 🔒 **دعاء كفارة المجلس** — ⚠️ **دائمًا آخر الدرس، بعد النشاط المصاحب** (سبحانك اللهم وبحمدك…)
10. 🔒 **العلاقة التكاملية لهذا اللقاء** + **فكرة للربط السريع** — ✏️ كيف يرتبط اللقاء ببقية المواد
11. 🔒 **مراجع للمعلمة** — ✏️ مراجع خاصة بالدرس

### المحتوى الخاص بكل مادة داخل «شرح الدرس» (✏️):
- **كتابي المنير:** الآيات المستهدفة + ترديد + المعنى + التطبيق السلوكي.
- **علّمني ربي (الرئيسية):** الآية الكونية + التفكّر + المعنى الإيماني + السلوك.
- **أحبك ربي:** اسم الله + معناه + أثره + الدعاء به.
- **قال رسولي:** الحديث + الراوي + المعنى + الاقتداء العملي + بطاقة الاعتقاد في النبي ﷺ.
- **أدب واقتداء:** الأدب + دليله + التمثيل العملي + الموقف.
- **لساني عربي:** الحرف/الحركة/التهجئة + النطق + القراءة.
- **مهاراتي:** المفهوم الرياضي + المحسوس + الرمز.
